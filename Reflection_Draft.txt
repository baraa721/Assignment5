One challenge in this assignment was making sure the programs handled incorrect input without stopping. In ScoreWriter, I used a loop to check whether scores were between 0 and 100 and ask again if they were not valid. I also learned how PrintStream can save information to a text file and how Scanner can read that information back. For ScoreReport, reading each line separately made it easier to skip blank lines and calculate each student's average. Testing with an incorrect file name helped me understand why checking whether a file can be read is important. This assignment helped me see how two separate Java programs can work together through a text file.
