One challenge I had with this assignment was making sure the program did not accept scores outside the range of 0 to 100. I used loops to keep asking for a score until the user entered a valid number. Another challenge was reading the text file correctly, especially when the file contained an extra blank line. Using nextLine() and a second Scanner helped keep each student's information together. I also learned that both programs need to run in the correct folder so the report program can find scores.txt. This assignment helped me better understand how Java writes data to a file and then reads that data back.
